# Valencia Town

A cinematic, mobile-first static website for Valencia Town at Shahna on the Indore–Ujjain corridor. Semantic HTML generated by Python, project WebP renders, Google Fonts, and a motion layer (GSAP + ScrollTrigger + Lenis, vendored) that loads after the page and never under reduced motion. No framework or production dependencies; deployed as static files on Vercel.

## Preview

Run `python -m http.server 4173 --bind 127.0.0.1` from this directory, then open `http://127.0.0.1:4173`.

## Build

`python -m pip install -r scripts/requirements.txt`, then:

- `python scripts/build.py` — production build (commit this). Values missing from `site.config.json` are left off the page and listed in the terminal.
- `python scripts/build.py --dev` — development build. Missing values show on the page as yellow `[KEY NAME]` markers. Do not deploy it.

The build writes `index.html`, `css/style.css` (from `css/parts/`), `js/main.js` (from `js/parts/`), `robots.txt` and `sitemap.xml`. Edit the parts, not the generated files. After stylesheet or script changes, bump `ASSET_VERSION` in `scripts/vt.py`.

## Where to change things

- `site.config.json` — everything awaiting client confirmation: phone, WhatsApp, email, developer, legal entity, MP RERA number and URL, approvals, price, payment plan, Godrej distance and source, film, documents, Tomorrow milestones, `ENABLE_HINDI`. Never fill a value without a source.
- `data/project.json` — confirmed facts: acres, plot sizes, distances, coordinates, masterplan zones, lead endpoint.
- `content/en.json` — all copy. A Hindi site is `content/hi.json` with the same keys plus `ENABLE_HINDI: true`; it builds to `/hi/`.
- `scripts/chapters/` — one file per chapter; order in `scripts/build.py`.

See `CHANGES.md` for the redesign, the image review list and the launch checklist.

## Lead handling

See `apps-script/README.md`. The form posts the same JSON as before; `interest` is the ticked checkboxes joined with commas. Success shows only after a readable `{"ok": true}`; failure keeps the visitor's entries. Personal fields never go to the analytics data layer.

## Verification

`python -m pip install -r scripts/requirements-qa.txt`, start the local server, then `python scripts/qa.py`. It checks overflow, 12px minimum text, 44px targets, button names, alt text, identical nav labels, the mocked lead form, Esc and console errors at 360, 390, 768, 1024 and 1440px, with and without reduced motion. Screenshots go to the ignored `qa/` folder.
