# Cinematic redesign: changes

The site is now a film in ten chapters plus an epilogue. Stack and deployment are unchanged: static HTML generated by Python (`scripts/build.py`), committed and served by Vercel. No framework was added. GSAP, ScrollTrigger and Lenis are vendored in `assets/vendor/` and load only after the page is idle, and never when the visitor prefers reduced motion.

## Where things live

| File | Holds |
|---|---|
| `site.config.json` | Every value still needing client confirmation (placeholders), flags, Godrej source, Tomorrow milestones |
| `data/project.json` | Confirmed project facts: acres, plot sizes, distances, coordinates, masterplan zones |
| `content/en.json` | All visible copy (ready for a `content/hi.json`) |
| `scripts/chapters/*.py` | One file per chapter |
| `css/parts/`, `js/parts/` | Styles and scripts per chapter; the build concatenates them into `css/style.css` and `js/main.js` |

`python scripts/build.py --dev` shows each missing value on the page as a yellow `[KEY NAME]` marker. `python scripts/build.py` (the version to commit and deploy) leaves those elements out and prints the list of what is still missing.

## Deviations from the brief

- **Removed at the client's request:** the vertical progress rail and "Scroll to begin". A thin progress line remains above the mobile contact bar.
- **Hero intro in CSS, not GSAP.** The motion libraries cost about 400ms of main-thread time on mobile. The intro, title rise and Ken Burns now run as CSS keyframes, and GSAP/Lenis load after the page is idle. Mobile Lighthouse (local, gzip): Performance 98, Accessibility 100, LCP 2.0s, CLS 0.03.
- **Tomorrow pins sideways only if the row overflows.** With today's three sourced milestones it fits the screen, so it shows as a row.
- **The Plan is framed, not full-bleed.** The only masterplan is 832px wide.
- **"Today · Plots open"** is shown without an external source, because it is the project's own status.
- **Bone sections use a darker amber (`#8A5A12`)** for the accent, because `#E2A84B` on bone fails contrast.
- **Mobile top bar is 40px.** Buttons in it keep a 44px touch area.
- **Config is `site.config.json`**, not `.ts`, because the build is Python.
- **Gallery has three images, not four.** The pool render was dropped so the site does not imply a pool.
