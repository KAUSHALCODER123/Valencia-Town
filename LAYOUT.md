# Layout

The page is a short film in chapters: dark, letterboxed, one idea per screen.

I Arrival (`#top`) → II Mahakal → III The Road (`#location`) → IV Growth (bone) → V Tomorrow → VI The Plan → VII Life (+ "A closer look" gallery) → VIII Plots (bone) → IX Trust → X Visit → Questions (`#faq`) → Footer.

Each chapter opens with a top-centre label (`CHAPTER III · THE ROAD`), an uppercase Cormorant title with one amber `<em>` phrase, and an italic supporting line. Full-bleed renders get letterbox bars, the shared grade and vignette, and an "Artist's impression" label bottom-right. Chapters are rendered by `scripts/chapters/*.py`; see `CHANGES.md` for details.
